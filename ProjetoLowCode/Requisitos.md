# 📋 Requisitos do Projeto

## 📌 Projeto
Sistema de Automação de Cadastro e Gerenciamento de Usuários utilizando abordagem Low Code / No Code / Vibecode.

---

# 🎯 Objetivo Geral

Desenvolver um protótipo funcional capaz de automatizar o processo de cadastro de usuários, armazenamento de informações e envio automático de notificações utilizando plataformas visuais e integrações automatizadas.

---

# ✅ Requisitos Funcionais

## RF01 – Cadastro de Usuários
O sistema deve permitir o cadastro de usuários contendo:

- Nome;
- E-mail;
- Telefone;
- Data de cadastro.

---

## RF02 – Armazenamento de Dados
O sistema deve armazenar automaticamente os dados cadastrados em uma base integrada ou planilha online.

---

## RF03 – Envio Automático de E-mails
O sistema deve enviar automaticamente um e-mail de confirmação após o cadastro do usuário.

---

## RF04 – Visualização de Registros
O sistema deve permitir a visualização dos usuários cadastrados.

---

## RF05 – Automação de Fluxos
O sistema deve executar automaticamente os fluxos configurados sem intervenção manual.

---

## RF06 – Integração com APIs
O sistema deve permitir integração com serviços externos via API.

---

# ⚙️ Requisitos Não Funcionais

## RNF01 – Usabilidade
A interface deve ser simples, intuitiva e de fácil utilização.

---

## RNF02 – Performance
Os fluxos automatizados devem executar em tempo adequado sem atrasos excessivos.

---

## RNF03 – Disponibilidade
O sistema deve estar acessível durante o período de testes e apresentações.

---

## RNF04 – Segurança
Os dados cadastrados devem ser protegidos e utilizados apenas para fins acadêmicos.

---

## RNF05 – Escalabilidade
A solução deve permitir futuras expansões e integrações.

---

# 🛠️ Requisitos Técnicos

- Utilização de plataforma Low Code/No Code;
- Integração com serviços de e-mail;
- Uso de repositório GitHub;
- Documentação organizada em Markdown;
- Estrutura modular do projeto.

---

# 📝 Critérios de Aceitação

O projeto será considerado concluído quando:

- O cadastro de usuários funcionar corretamente;

- O e-mail automático for enviado;
- O repositório estiver organizado;
- A documentação estiver completa;
