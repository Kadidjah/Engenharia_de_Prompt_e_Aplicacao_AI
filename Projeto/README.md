# Site da Professora Kadidja

## 📚 Sobre

Este é um site profissional dedicado à Professora Kadidja, especialista em **Engenharia de Prompt** e **Aplicações de Inteligência Artificial**. O site apresenta informações sobre suas disciplinas, pesquisas e oferece um meio de contato.

## 🎯 Disciplinas

- **Engenharia de Prompt e Aplicação de IA** (2026_1)
  - Cursos para: Ciência da Computação, ADS, Engenharia de Software e Sistemas de Informação
  
- **Programação Assistida por IA**
  - Desenvolvimento com suporte de ferramentas de IA
  
- **Automação com IA**
  - Implementação de soluções inteligentes

## 🔧 Como Usar

1. Abra `index.html` em seu navegador
2. Navegue pelas seções usando o menu
3. Preencha o formulário de contato para enviar mensagens

## 📝 Personalização

Para personalizar o site:

1. **Email**: Altere em `index.html` na seção de contato
2. **Cores**: Modifique as variáveis CSS no `:root` em `styles.css`
3. **Conteúdo**: Edite o texto diretamente no `index.html`
4. **Logo**: Substitua o texto "Prof. Kadidja" por uma imagem
