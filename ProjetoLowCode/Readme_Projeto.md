# 🚀 Projeto Módulo 3 – Low Code / No Code / Vibecode

## 📌 Sobre o Projeto

Este repositório contém o desenvolvimento do projeto proposto na Unidade 3 da disciplina, com foco em soluções utilizando abordagens **Low Code**, **No Code** e **Vibecode**.

O objetivo principal foi criar um protótipo funcional capaz de automatizar processos de cadastro e gerenciamento de usuários, utilizando plataformas visuais e integrações automatizadas.

---

# 🎯 Objetivo

Desenvolver uma aplicação de prototipagem rápida utilizando ferramentas low code/no code, explorando:

- Automação de processos;
- Integração entre plataformas;
- Criação de interfaces visuais;
- Fluxos automatizados;
- Redução do tempo de desenvolvimento.

---

# 🖥️ Funcionalidades

✅ Cadastro de usuários  
✅ Armazenamento automatizado de dados  
✅ Envio automático de e-mails  
✅ Fluxos de automação integrados  
✅ Interface simplificada para testes e validação  

---

# 🛠️ Plataforma Utilizada

### Make (Integromat)

A plataforma foi escolhida devido à sua:

- Facilidade de integração;
- Interface visual intuitiva;
- Rapidez na criação de automações;
- Suporte a múltiplos serviços e APIs.
